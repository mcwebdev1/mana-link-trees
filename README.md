# Mana Hubs

Link-in-bio pages for Mana Common’s Hubs, Common, Fashion, and Tech cards.

Mana Hubs is the coworking card: a portrait card over a photo of the space, with links to book a tour, Mana Hubs curated by Mana Tech, and the Biscayne Showroom by Mana Fashion, plus Facebook, Instagram, and LinkedIn. Mana Common, Mana Fashion Services, and Mana Tech are the matching cards.

## Run locally

```bash
npm install
npm run dev
```

The dev server listens on all interfaces at port 4177.

## Pages

- [Mana Hubs](http://127.0.0.1:4177/)
- [Mana Common](http://127.0.0.1:4177/common)
- [Mana Fashion](http://127.0.0.1:4177/fashion)
- [Mana Tech](http://127.0.0.1:4177/tech)

A bar at the top of each page links Hubs, Common, Fashion, and Tech.
