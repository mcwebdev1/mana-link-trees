# Mana Hubs

Link-in-bio page for Mana Hubs, Mana Common’s coworking space in downtown Miami.

The page follows the **Card - Hubs** frame from Mana Common Link Trees 2026: a portrait card over a photo of the space, with tour and showroom links plus social profiles.

## Run locally

```bash
npm install
npm run dev
```

The dev server listens on all interfaces at port **4177**.

Open [http://127.0.0.1:4177](http://127.0.0.1:4177).
